# tg_ai_bot

Telegram-клиент для нейросетей: один бот — много провайдеров, моделей и API-ключей.

## Возможности

- **Провайдеры.**
  - Нативно: OpenAI, Anthropic Claude, Google Gemini.
  - Через `type: openai` + `base_url`: DeepSeek, OpenRouter, xAI Grok, Mistral, Groq, Qwen, Ollama, LM Studio, vLLM и любой другой OpenAI-совместимый API.
- **Выбор модели.** `/model` → провайдер → модель. Список берётся из API (кэшируется на час, есть кнопка «Обновить») или из конфига. Модель можно задать и вручную: `/model имя-модели`.
- **API-ключи задаются прямо в боте.** `/keys` → провайдер → «➕ Добавить ключ». Бот проверяет ключ, сразу удаляет сообщение с ним из чата и хранит ключ в своей базе. Там же удаление и лимиты.
- **Несколько ключей на провайдера.** Бот работает на первом рабочем ключе. Когда ключ упирается в лимит, бот переключается на следующий. Срабатывают и твои лимиты (rpm/rpd/tpd), и ответы API: 429, кончилась квота, отклонённый ключ, 5xx.
- **Лимиты.**
  - На каждый ключ: запросы в минуту и в сутки, токены в сутки.
  - На каждого пользователя: сообщения, токены и картинки в сутки, с индивидуальными исключениями.
  - Счётчики хранятся в SQLite и переживают перезапуск.
- **Голосовые.** Голосовые, кружки и аудиофайлы распознаются через Whisper (Groq или OpenAI) или Gemini, затем уходят нейросети как текст. Движки перебираются по порядку, у каждого своя ротация ключей.
- **Доступ.** Управляется прямо из бота. Незнакомец пишет боту — админам приходит заявка с кнопками «Пользователь / Админ / Отклонить». Есть и команды `/adduser`, `/addadmin`, `/deluser`, `/block`.
- **Вход.** Текст, фото, альбомы, файлы: PDF, DOCX, XLSX, любой текст и код. В OpenAI, Claude и Gemini PDF уходит как файл, остальным — извлечённым текстом.
- **Выход.**
  - Текст с форматированием и картинки.
  - Файлы: модель оборачивает содержимое в `<file name="...">`, бот присылает его документом. `.docx` и `.xlsx` бот собирает сам из Markdown и CSV.
- **Картинки.** `/img описание` генерирует картинку, а ответом на фото — редактирует его. Image-модели Gemini и OpenRouter присылают картинки прямо в чате.
- **Прочее.** Контекст диалога, свой системный промпт (`/system`), прокси (SOCKS5/HTTP) для Telegram и для API.

## Установка на Debian (служба systemd)

Подходит Debian 12/13 и Ubuntu 22.04+, нужен Python 3.10+.

```bash
sudo apt install -y git
sudo git clone https://github.com/ArtemDNK/tg_ai_bot /opt/tg_ai_bot
cd /opt/tg_ai_bot
sudo ./install.sh
```

Установщик спросит:

1. **Токен бота** от [@BotFather](https://t.me/BotFather).
2. **Telegram ID главного админа** (узнать: [@userinfobot](https://t.me/userinfobot)). Можно несколько через пробел. Главных админов нельзя снять из бота, только в конфиге.

Что делает `install.sh`:

- ставит `python3-venv`;
- создаёт системного пользователя `tgaibot` и venv с последними версиями зависимостей;
- собирает `config.yaml` из шаблона с сохранением комментариев;
- выставляет права: `config.yaml` читает только служба, писать служба может только в `data/`;
- регистрирует и запускает службу `tg-ai-bot` с изоляцией (`ProtectSystem=strict`, `NoNewPrivileges` и т.д.).

Повторный запуск безопасен: конфиг и данные не трогаются.

После установки напиши боту `/keys` и добавь ключи нужных нейросетей, затем выбери модель через `/model`.

### API-ключи

`/keys` показывает всех провайдеров с числом ключей и их состоянием. Внутри провайдера:

- **➕ Добавить ключ.** Пришли ключ или несколько, по одному на строку. Лимиты можно указать сразу: `КЛЮЧ name=основной rpm=10 rpd=250 tpd=0`. Бот делает пробный запрос: отклонённый API ключ не добавляется, а при сетевой ошибке ключ добавляется с предупреждением. Сообщение с ключом бот удаляет из чата.
- **⚙️ Лимиты N** — запросы в минуту, запросы в сутки, токены в сутки (`10 250 0`).
- **🗑 Удалить N.**
- **⏯ Снять паузы** — вернуть в ротацию ключи, поставленные на паузу после ошибок.

Ключи используются в порядке добавления. Можно и командой: `/addkey gemini AIza... rpm=10 rpd=250`.

Менять ключи могут только главные админы из `config.yaml`, остальные админы видят лишь состояние. Ключи из бота хранятся в `data/bot.sqlite3`: папка доступна только службе. Ключи можно по-прежнему прописывать и в `config.yaml`, в боте они помечены «config.yaml» и правятся только там.

Новых провайдеров (свой `base_url`, например локальный Ollama) добавляют в `config.yaml` по образцу из `config.example.yaml`, а ключи к ним — уже из бота.

### Управление

```bash
journalctl -u tg-ai-bot -f              # логи
sudo systemctl restart tg-ai-bot        # перезапуск
sudo nano /opt/tg_ai_bot/config.yaml    # настройки → затем /reload в боте
sudo /opt/tg_ai_bot/update.sh           # git pull + обновить зависимости + перезапуск
```

Тонкая настройка в `config.yaml`: лимиты пользователей, модели по умолчанию, движки распознавания, прокси. Все поля описаны в `config.example.yaml`.

## Команды

| Команда | Что делает |
|---|---|
| `/model` | выбрать провайдера и модель (`/model имя` — вручную) |
| `/new` | очистить контекст |
| `/img текст` | сгенерировать картинку; ответом на фото — отредактировать |
| `/system текст` | системный промпт (`reset` — по умолчанию, `off` — без него) |
| `/status` | текущая модель и расход за сутки |

**Админы:**

| Команда | Что делает |
|---|---|
| `/users` | кто имеет доступ |
| `/adduser id [имя]` | дать доступ |
| `/addadmin id [имя]` | сделать админом (только главные админы) |
| `/deluser id` | отозвать доступ |
| `/block id` | заблокировать (бот перестаёт отвечать и не шлёт заявки) |
| `/keys` | API-ключи: добавить, удалить, лимиты, состояние и паузы |
| `/addkey провайдер КЛЮЧ` | добавить ключ командой |
| `/reload` | перечитать `config.yaml` без перезапуска |

Админы, добавленные через бота, могут выдавать и отзывать доступ пользователям. Назначать и снимать админов могут только главные админы из конфига.

## Как работает ротация ключей

| Ответ API | Что делает бот |
|---|---|
| 429 rate limit | пауза ключа на `Retry-After` (или 60 с), запрос сразу уходит на следующий ключ |
| кончилась квота или баланс | пауза до 1 ч (не дольше, чем до полуночи), следующий ключ |
| 401/403, невалидный ключ | пауза 24 ч и уведомление админам |
| 5xx, таймаут, обрыв | пауза 20 с, следующий ключ |
| 400 и прочие ошибки запроса | ключ не трогается, ошибка показывается пользователю |

Локальные лимиты из конфига проверяются до запроса: ключ, исчерпавший `rpm`, `rpd` или `tpd`, пропускается. Если свободных ключей нет, бот пишет, когда освободится ближайший.

## Ограничения

- Telegram не даёт ботам скачивать файлы больше 20 МБ (на стандартном Bot API).
- Ответы приходят целиком, без стриминга.
